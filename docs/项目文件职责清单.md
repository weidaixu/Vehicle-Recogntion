# DriveScope 项目文件职责清单

本文档对应清理后的 DriveScope 项目。它说明各文件或同类目录负责什么、是否影响运行，以及哪些内容可以重新生成。训练图片数量很多，因此图片按目录说明，不逐张重复列出。

## 一、程序入口

| 文件 | 具体职责 | 运行时是否必需 |
| --- | --- | --- |
| `backend/main.py` | 创建 FastAPI 应用、加载模型与服务、注册全部 API 路由，提供 `/api/status`。后端启动入口是 `backend.main:app`。 | 是 |
| `frontend/src/main.tsx` | React 浏览器入口，把 `App` 挂载到 `index.html`。 | 是 |
| `frontend/src/App.tsx` | 主页面及核心交互：7:3 聊天/工具区、图片上传、连续追问、识别结果、设计语言、多视角资料和历史档案。 | 是 |
| `train.py` | 训练、验证、阈值评估和批量预测入口；默认读取 `prepared_final/`。教师测试集到位后可用 `--predict-dir` 生成 `predictions.csv`。 | 仅训练或批量推理时 |
| `data_pipeline.py` | 从教师原始 `train/val` 中确定 50 个目标车型，构造目标车型加 `unknown` 的 `prepared_final/` 数据集并检查图片去重。 | 仅重新准备数据时 |

旧的 Streamlit `app.py` 已删除。当前唯一网站实现是 FastAPI + React/Vite。

## 二、后端源码 `backend/`

| 文件 | 具体职责 |
| --- | --- |
| `backend/__init__.py` | 标记后端 Python 包。 |
| `backend/main.py` | 应用装配、状态接口、CORS 与路由注册。 |
| `backend/schemas.py` | API 请求和响应的 Pydantic 数据结构，统一字段校验。 |
| `backend/services.py` | 初始化并共享分类器、Session 存储、Wikimedia 客户端等服务。 |
| `backend/deepseek_client.py` | 调用 `deepseek-v4-flash`，声明工具 schema，解析模型返回的真实 tool calls；只从环境变量读取密钥。 |
| `backend/agent_runtime.py` | Agent 循环核心：执行模型发起的工具、校验参数、记录耗时与结果，并对低置信度或 `unknown` 强制中断。 |
| `backend/session_store.py` | SQLite 持久化：Session、图片引用、消息、识别结果、设计分析、工具轨迹、视觉档案和图板。 |
| `backend/wikimedia.py` | 检索 Wikimedia Commons 车型图片并整理作者、许可证、来源链接等元数据。 |
| `backend/board_renderer.py` | 把车型、设计语言和多视角图片渲染为设计图板及来源清单。 |
| `backend/routes/__init__.py` | 标记 API 路由包。 |
| `backend/routes/agent.py` | `/api/agent/upload`、`/api/agent` 与 Session 查询接口，连接上传、对话和 Agent 循环。 |
| `backend/routes/classification.py` | 本地车型分类接口，验证图片并调用 ResNet18。 |
| `backend/routes/catalog.py` | 读取目标车型目录与车型基础信息。 |
| `backend/routes/design_language.py` | 设计语言分析接口。 |
| `backend/routes/vehicle_views.py` | 多视角图片接口，支持合规网络来源与本地数据回退。 |
| `backend/routes/design_board.py` | 设计图板生成接口。 |
| `backend/routes/archives.py` | 档案保存和历史检索接口。 |

## 三、模型与业务工具

| 文件或目录 | 具体职责 | 删除规则 |
| --- | --- | --- |
| `agent_tools.py` | 加载 `output/model.pt` 的 `VehicleClassifier`，实现本地推理、Top-3 和拒识；还保留基础车型查询与收藏工具。后端运行依赖此文件。 | 不可删除 |
| `output/model.pt` | 当前正式自训练 ResNet18 权重，51 类，包含类别、归一化参数、训练配置、验证指标和拒识阈值。 | 不可删除 |
| `output/experiments/baseline_clean/` | 基线实验配置、指标和模型。 | 训练证据，不可删除 |
| `output/experiments/finetune_stage1/` | 第一阶段 12 个 epoch 的历史、最佳/最终检查点和配置。 | 训练证据，不可删除 |
| `output/experiments/finetune_stage2/` | 第二阶段 8 个 epoch 的完整历史、指标、最佳/最终模型、混淆矩阵和每类指标。 | 核心训练证据，不可删除 |
| `output/experiments/stage1_on_final_data/` | 正式数据上的阶段性评估配置与指标。 | 训练证据，不可删除 |
| `output/vehicle_agent.sqlite` | 真实业务运行数据库。 | 不可当缓存删除 |
| `output/session-images/` | 上传图片的受控本地引用；DeepSeek 不接收图片本身。 | 有会话时不可删除 |
| `output/boards/` | 已生成的设计图板及来源清单。 | 有档案时不可删除 |

历史实验配置中的 `prepared_clean` 是当时实验的数据路径记录，必须原样保留作为证据；当前程序默认使用 `prepared_final`。

## 四、数据目录

| 文件或目录 | 具体职责 | 删除规则 |
| --- | --- | --- |
| `train/` | 教师提供的 827 类原始训练图片，也可作为本地多视角资料源。 | 原始数据，不可删除 |
| `val/` | 教师提供的原始验证图片。 | 原始数据，不可删除 |
| `prepared_final/train/` | 50 个目标车型加 `unknown` 的正式训练集。 | 当前模型数据，不可删除 |
| `prepared_final/val/` | 正式验证集，也是本地推理测试样本来源。 | 当前测试数据，不可删除 |
| `prepared_final/label_map.json` | 51 个模型输出类别的顺序映射。 | 不可删除 |
| `classes.txt` | 50 个目标车型 ID；`unknown` 由程序作为第 51 类追加。 | 不可删除 |
| `selected_classes.json` | 目标车型名称、品牌和原始样本数量等说明。 | 不可删除 |
| `cls_info/class_info.json` | 教师数据的完整车型元信息。 | 不可删除 |
| `inputs/` | 本地批量推理输入目录或课程样例输入。 | 按实际测试需要保留 |

已被正式数据替代的 `prepared/`、`prepared_clean/` 已清理，避免保留约 1 GB 重复图片。

## 八、配置和环境

| 文件或目录 | 具体职责 |
| --- | --- |
| `requirements.txt` | Python 训练、推理、FastAPI、测试和文档生成依赖。 |
| `pytest.ini` | pytest 搜索路径与运行配置。 |

DeepSeek 密钥只从当前后端进程的 `DEEPSEEK_API_KEY` 环境变量读取。项目文件中不应保存密钥。

## 九、可再生成与不可删除清单

可以安全再生成：`build-output/`、Python 缓存、pytest 缓存、TypeScript 增量缓存、`frontend/node_modules/`。

必须保护：`train/`、`val/`、`prepared_final/`、`output/model.pt`、`output/experiments/`、`output/vehicle_agent.sqlite`、`output/session-images/`、`output/boards/`、`frontend/public/assets/showroom-original.jpg`、课程任务书和正式报告。

## 十、本次清理说明

- 删除旧 Streamlit 页面、已取消的驾驶舱启动页、旧背景资源与重复背景副本。
- 删除 `prepared/`、`prepared_clean/` 两套已被 `prepared_final/` 替代的数据。
- 删除旧 `frontend/dist/`、根目录旧 `build-output/`、临时 PDF 依赖和各类缓存；生产构建会重新生成 `build-output/`。
- 测试样本和程序默认数据路径统一改为 `prepared_final/`。
- 删除声明中的 GSAP 依赖；若本机 `node_modules/.pnpm` 中仍有不可写的包存储残留，它不再被 package.json、锁文件或代码引用，重新执行干净安装时会自然消失。
